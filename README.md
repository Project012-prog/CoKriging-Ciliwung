# Spatial Analysis of Ciliwung River Water Quality using Ordinary Cokriging

[![Python Version](https://img.shields.io/badge/python-3.8%2B-blue.svg)](https://www.python.org/)
[![License: MIT](https://img.shields.io/badge/License-MIT-yellow.svg)](LICENSE)

This repository contains a geostatistical spatial analysis project aimed at mapping and estimating **Biochemical Oxygen Demand (BOD)** levels along the Ciliwung River corridor in DKI Jakarta using **Ordinary Cokriging**. **Chemical Oxygen Demand (COD)** is utilized as an auxiliary/secondary variable to improve spatial prediction accuracy.
